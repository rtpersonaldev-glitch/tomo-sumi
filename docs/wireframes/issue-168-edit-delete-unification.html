Issue #168 — 編集・削除ボタン統一

ワイヤーフレーム v1 | 承認後に実装へ進む

統一パターン概要

パターン 操作 適用画面
A: ・・・メニュー カード右上「⋯」→ドロップダウン（編集/削除） 投稿詳細・お知らせ詳細・予定詳細・TODOリスト詳細・アルバム詳細・コスト詳細・
リマインダーグループ
B: スワイプ削除 行を左スワイプ →「削除」アクション表示 TODOリスト・リマインダー各項目
C: エリアタップで編集 行全体タップ → 編集画面へ遷移 固定費一覧・リマインダー各項目（編集）
D: ボタンなし 編集・削除ボタンを除去 投稿一覧

パターン A — 「⋯」ドロップダウンメニュー（詳細画面）

適用: 投稿詳細 / お知らせ詳細 / 予定詳細 / TODO詳細 / アルバム詳細 / コスト詳細

通常表示

← 投稿詳細
⋯
タイトルテキスト
山田太郎 · 2時間前
投稿の内容がここに表示されます。長い場合は省略されます…

→ カード右上ではなく、ページヘッダー右端に「⋯」を配置する

「⋯」クリック後

← 投稿詳細
⋯
✏ 編集
🗑 削除
タイトルテキスト
山田太郎 · 2時間前
投稿内容…

→ ドロップダウンはheader右端直下に表示。削除は赤色テキスト
