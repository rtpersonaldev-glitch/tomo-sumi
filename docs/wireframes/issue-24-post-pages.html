実装メモ

  • PostListPage: 投稿カード一覧、いいね/コメント数、投稿者アバター表示（useHomeMembers から引き当て）
  • PostDetailPage: フル本文（HTML 描画）、画像ギャラリー、いいねボタン（楽観的更新）、コメント一覧・追加・削除
  • PostEditPage 作成: Tiptap エディタ（StarterKit + Placeholder）、react-cropper による複数画像クロップ → FormData 送信
  • PostEditPage 編集: テキスト内容のみ更新（PUT は JSON body）、既存画像は表示のみ
  • いいね楽観的更新: onMutate でキャッシュ内 is_liked / like_count を即時反転、onError でロールバック
  • created_by: バックエンドスキーマに追加 → フロントで homeMembers から nickname/avatar 表示
  • Tiptap 出力: editor.getHTML() → FormData の content フィールドへ、表示は dangerouslySetInnerHTML
