実装メモ
FullCalendar プラグイン: dayGridPlugin（月表示）+ interactionPlugin（dateClick）
@fullcalendar/interaction: 未インストール → npm install で追加
一覧タブ: API から全スケジュール取得 → 開始日時順ソート → 日付でグループ化して表示
作成者表示（バックエンド変更必要）: ScheduleResponse に created_by: int | None を追加（schemas.py 1行追加）→ フロントで GET /api/homes/{homeId}/users からメンバー一覧取得 → ID照合でニックネーム・アバター表示
表示箇所: 一覧カード（アバター＋名前チップ）/ 詳細ページ（👤 作成者 行）/ カレンダービューは非表示
日時型: バックエンドは datetime（ISO 8601 + TZ）、フォームは datetime-local（"YYYY-MM-DDTHH:mm"）
変換: 送信時 → new Date(localString).toISOString()、表示時 → format(parseISO(str), "yyyy年M月d日 HH:mm", {locale: ja})
カレンダー日付範囲: datesSet コールバックで取得し、API の ?start=&end= に渡す
dateClick: クリックした日付を ?date=YYYY-MM-DD で /schedules/new に渡す
query key: list = ["schedules", homeId] / detail = ["schedule", id] / members = ["home-members", homeId]
isEdit: const isEdit = !!id（useParams）、作成時は id が undefined
